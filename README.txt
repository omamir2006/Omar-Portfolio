OMAR AMIR — PORTFOLIO WEBSITE

Files:
- index.html
- styles.css
- script.js
- assets/

How to use locally:
1. Open index.html in any modern browser.

How to publish free:
Option A — GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the assets folder.
3. Go to Settings > Pages.
4. Choose the main branch and /root.
5. GitHub will give you a public URL.

Option B — Netlify
1. Go to Netlify Drop.
2. Drag the entire omar_portfolio_site folder onto the page.
3. Netlify will publish it and give you a URL.

You can edit your email/phone in the contact section of index.html.
